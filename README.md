## ✨ Included Projects

### ✅ Task Manager Pro (WorkApp)
- 🔐 **Authentication** — Sign In / Sign Up, with Facebook, Instagram, and Google sign-in options
- ✅ **Task management** — create, edit, complete, and delete tasks with date & time scheduling
- 💾 **Local persistence** — tasks and user data saved with SharedPreferences, full CRUD functionality
- 👤 **Profile management** — edit personal details (name, email), change password, delete account
- 🌗 **Dark Mode toggle** — accessible from the app drawer
- ℹ️ **About Us** — in-app info screen with developer details and app version
- 🎨 Clean, themed UI with a consistent dark color palette across all screens

### 🧩 Other Practice Exercises
- Smaller widget and state-management exercises used to build core Flutter fundamentals during self-learning
